# CodeAlpha Hangman Game 🎮

A simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Description

Hangman is a word guessing game where the player tries to guess a hidden word one letter at a time.
The player has a maximum of 6 incorrect guesses. The game ends when the player successfully guesses the complete word or uses all 6 incorrect attempts.

## ✨ Features

- Random word selection
- 5 predefined words
- Letter-by-letter guessing
- Maximum 6 incorrect guesses
- Prevents repeated guesses
- Displays guessed letters
- Displays remaining attempts
- Win and Game Over messages
- Simple console-based interface

## 🛠️ Technologies Used

- Python
- Random Module
- Lists
- Strings
- While Loop
- If-Else Conditions

## ▶️ How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in Command Prompt or VS Code.
4. Run:

python hangman.py

## 🎮 Game Rules

- Guess one letter at a time.
- Correct letters are revealed.
- Each incorrect guess reduces the remaining attempts.
- Maximum incorrect guesses: 6.
- Guess the complete word before all attempts are used to win.
